# Libraries

Esta carpeta contiene exclusivamente herramientas reutilizables e independientes de las reglas de negocio de un sistema institucional.

Cada biblioteca debe tener un propósito explícito y documentación de su API y uso. No se deben agregar aquí procesos propios de un sistema, como registrar convenios o aprobar titulaciones.

## Ejemplos previstos

- Buscadores y selectores institucionales.
- Componentes reutilizables de tablas.
- Exportadores de documentos.
- Validadores independientes del negocio.
