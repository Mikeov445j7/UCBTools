# CrudNominaciones (`libraries/crud-nominaciones`)

Librería Angular 18 (NgModule) institucional para el alta, baja, modificación y consulta de nominaciones de títulos académicos UCB.

## Componentes
- `ucb-gestion-nominaciones`: Vistas integradas de búsqueda, listado en tarjetas y gestión.
- `ucb-formulario-nominacion`: Formulario reactivo para alta y edición de nominaciones.

## Servicio
- `NominacionesService`: 8 endpoints de integración con `ApiTitulacionOficial/api/Nominaciones`.

## Uso
```html
<ucb-gestion-nominaciones></ucb-gestion-nominaciones>
```
